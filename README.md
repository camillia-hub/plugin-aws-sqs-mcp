# AWS SQS MCP

Works with Amazon SQS queues. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/aws-sqs-mcp

Installs from the Camillia hub as `aws-sqs-mcp-e8966d`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
